## 5. Architecture summary

scikit-learn-compatible: estimators inherit `BaseOptimization`/`skb.BaseEstimator` and use `sklearn.utils.metadata_routing`/`validation` (confirmed by imports in `_mean_risk.py`, `_nco.py`). Convex optimization backend is CVXPY (`import cvxpy as cp`, confirmed in `optimization/convex/_base.py`), default solver `CLARABEL` (Rust-based interior point), with documented fallback to `SCIP` for mixed-integer/cardinality constraints. Dependencies pinned in `pyproject.toml`: `numpy>=1.23.4`, `scipy>=1.15.2`, `pandas>=1.4.1`, `cvxpy-base>=1.5.0`. Cross-validation is a first-class module (`model_selection`) built on top of `sklearn.model_selection`, not bolted on.

## 6. Relevant modules — verified via direct source read, not README claims

- `optimization/cluster/hierarchical/_hrp.py` — **Hierarchical Risk Parity, confirmed present** (also `_herc.py` HERC, `_schur.py` Schur complement).
- `optimization/cluster/_nco.py` — **Nested Clusters Optimization, confirmed present**, explicitly attributed to López de Prado in the docstring.
- `optimization/convex/_mean_risk.py` — Mean-Risk optimization including **CVaR** (`RiskMeasure.CVAR`, `max_cvar`, `cvar_beta`) and **CDaR** (`RiskMeasure.CDAR`, `max_cdar`, `cdar_beta`) — confirmed via grep of source, not docs.
- `optimization/convex/_risk_budgeting.py`, `_maximum_diversification.py`, `_distributionally_robust.py`, `_benchmark_tracker.py`.
- `model_selection/_combinatorial.py` — **`CombinatorialPurgedCV`, confirmed present**, explicitly implementing purging and embargoing. Docstring cites López de Prado and credits "Implementation derived from: scikit-portfolio, Copyright (c) 2022, Carlo Nicolini." CPCV is real and present, not name-only.
- `model_selection/_walk_forward.py`, `_multiple_randomized_cv.py` — additional financial-time-series CV methods.
- **No Black-Litterman module was confirmed.** A `prior/` directory exists but a Black-Litterman class inside it was not independently verified — flagged unresolved (§18).

## 10. Hidden defaults or semantic coupling — a good practice example, self-documented

HRP's own docstring explicitly flags a deviation from the source paper: "The original paper uses the variance as the risk measure and the single-linkage method... The default linkage method is set to the Ward variance minimization algorithm" — this is a promoted default the library itself documents and justifies, not silently inherited. NCO similarly documents its generalization beyond the original KMeans/min-variance/equal-weight paper defaults. **This is exactly the citation discipline this project's own global rules require, and skfolio does it — a genuinely good precedent to hold Signal Current's own code to.**

## 12. What Signal Current could reuse

Strong candidate to reuse the CPCV/walk-forward (`_combinatorial.py`) module directly as a dependency, avoiding a reimplementation of purge/embargo logic that Signal Current's own Reconciliation Matrix (rows 27, 28) already requires. The HRP/NCO/CVaR/CDaR optimizers are candidates for direct use or baseline comparison.

## 13. What Signal Current should not inherit

The CVXPY solver-selection UX — cardinality constraints silently require installing a separate mixed-integer solver (SCIP), a hidden external dependency trap. Do not assume Black-Litterman exists without independent confirmation (§6, §18).

## 14. Integration / coupling risks

Tight coupling to `sklearn`'s estimator/metadata-routing API and to CVXPY's solver ecosystem (version-pinned `cvxpy-base>=1.5.0`); adopting skfolio pulls in that whole dependency chain rather than isolating via a thin adapter, unless deliberately wrapped.

## 15. Required parity / golden tests

HRP and NCO docstrings cite the original López de Prado paper via reference markers, and explicitly document formula deviations (linkage method). MeanRisk (mean-variance/CVaR/CDaR) cites "Portfolio Optimization: Theory and Application," Daniel P. Palomar (2025), Chapters 7/10/13/14 — a citable textbook, not marketing language. **Recommend pulling the exact reference list from each module's `References` docstring section before writing parity tests** — this pass saw section headers but did not extract every full citation string.

## 16. Proposed disposition

**ADOPT (as a dependency) for CPCV/HRP/NCO/CVaR/CDaR, with WRAP (thin adapter) for the CVXPY-backed convex optimizers to isolate solver-dependency risk.** This is warranted, not merely reputational: license is clean BSD-3-Clause with no drift, maintenance is active (commits within days of this research), and the specific algorithms Signal Current cares about (HRP, NCO, CVaR, CDaR, CPCV) are all genuinely implemented with paper citations, not just named-and-absent. **This is the first candidate in this program to clear the bar for ADOPT rather than REFERENCE-only.**

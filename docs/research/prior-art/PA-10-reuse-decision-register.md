## Role vocabulary — no external engine is an oracle

Per the reconciliation matrix (`docs/specs/00-source-inventory-reconciliation.md`, row 16), external engines and libraries are **conformance systems, never alternate truth stores.** Signal Current semantics are derived from primary formulas, papers, and contracts first. External implementations may then be used as:

- **conformance comparator** — an independent implementation whose output we diff against ours to surface disagreement. Disagreement is a signal to go re-read the primary source, not evidence that the external side is right.
- **external regression fixture** — a pinned-version/pinned-commit output frozen as a change-detection fixture. Proves our behaviour did not drift; proves nothing about correctness.

The word "oracle" is deliberately not used for any external code in this register. Any row proposing comparator/fixture use must name the primary source that actually defines the semantics.

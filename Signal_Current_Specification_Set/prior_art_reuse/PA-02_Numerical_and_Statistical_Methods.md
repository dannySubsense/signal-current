# PA-02 — Numerical & Statistical Methods

Survey proven implementations and references for:
- purging and embargo;
- CPCV;
- probability/deflated Sharpe;
- White Reality Check / SPA-family approaches;
- bootstrap methods appropriate for dependent financial data;
- triple-barrier/event labeling;
- meta-labeling;
- sample uniqueness and weighting;
- regime/change-point methods;
- parameter sensitivity;
- Monte Carlo / path perturbation;
- multiple-testing corrections;
- performance/risk statistics.

For every method:
1. establish mathematical/reference definition;
2. compare available implementations;
3. create candidate golden examples;
4. determine Adopt / Adapt / Reference / native implementation;
5. record applicability conditions rather than making every method universal.

# PA-08 — Agent & Research Automation

Survey:
- Qlib RD-Agent and related research-agent systems;
- typed tool/agent frameworks;
- workflow engines with approval gates;
- sandbox and permission models;
- agent event/audit approaches;
- research-plan generation;
- literature/code search agents;
- evidence-grounded report generation.

Primary Signal Current question:
How can probabilistic agents operate a deterministic laboratory without becoming a source of numerical truth?

Required boundaries:
- typed tools only;
- permissions by stage;
- no direct mutation of immutable evidence;
- no lockbox access unless explicitly authorized;
- all campaign changes auditable;
- agents may propose, never self-certify.
